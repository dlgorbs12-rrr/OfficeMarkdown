# #9 오너 평가 봉투

신규 출시 평가는 [검색 설계와 출시 평가 v2](../release-protocol.md)를 따른다. 신규 판정표는 judgments.tsv의 열을 사용해 모든 과제·파일·페이지에 yes/weak/no/unreadable 중 하나를 입력하고 판정표.tsv로 저장한다. 페이지가 비어 있는 부재 행은 허용하지 않는다. 아래 1·2차 인계와 자동 비교는 이전 실험의 역사적 절차다.

## 1차 인계 · 검색 결과를 보기 전

기존 작성 요청의 과제 유형을 바탕으로 작업자가 구성한 질문 12개를 [tasks.tsv](tasks.tsv)에 고정했다. 구성·흐름·일정·세부 목적별 세 질문이다. 오너는 검색 결과를 보기 전에 실제 작성 상황과 맞는지 확인한다. 수정이 필요하면 사유와 변경된 질문 파일 해시를 원본 판정 전에 남긴다. 기존 개발 질문 8개와 해당 파일의 사본·개정본은 개발군에 둔다. 오너가 원본을 고를 때 검색 결과나 후보 목록은 열지 않는다.

1. 이전 탐색·개발에 쓰지 않은 PPTX 묶음을 지정한다. 원본을 읽을 수 있는 경로와 프로젝트·파일 계보를 알려 주거나, 로컬에서 [documents.tsv](documents.tsv)에 파일별 별칭·개정 계보·버전·경로를 채운다. 파일명 변경, 복제와 개정 전후를 같은 계보로 묶는다. 개발군과 중복이면 해당 계보 전체를 제외한다. 입력 당시의 SHA-256은 PowerShell에서 `Get-FileHash -LiteralPath $path -Algorithm SHA256`으로 얻는다. 장표 수와 합계를 적는다. 외부 이슈에는 경로와 본문을 올리지 않는다.
2. 독립 판정 전에 질문 파일과 원본 목록을 각각 해시하고 로컬에 사본을 보존한다. 두 해시와 파일 수·페이지 수를 #9에 남기면 자료 범위가 고정된다. 판정 도중 원본이 달라지면 이전 결과와 섞지 않고 별도 버전으로 기록한다.
3. 원본 미리보기에서 **모든 페이지**를 보며 과제별로 적합한 페이지를 빠짐없이 [judgments.tsv](judgments.tsv)에 기록한다. 적합은 “이 질문의 장표를 작성할 때 설명이나 예시로 직접 쓸 수 있다”로 판단한다. 그림 위주, 명시적 연결선 없음, 이름만 같은 오답은 표시한다. 부재는 전수 확인 후 해당 과제에 source_id·page를 비우고 suitable=no, reason=부재로 기록한다. 열리지 않은 원본은 판독 실패로 기록하고 부재와 구분한다.
4. 완료 후 판정표의 해시와 판독 가능 범위를 전달한다. 질문·원본을 바꾸지 않는다. 그림 위주·미연결·동명 오답·실제 부재 중 확보되지 않은 조건은 평가 공백으로 보고한다. 예상 준비·판정 시간은 60장 내외에서 약 60~100분이다. 실제 소요 시간과 분모를 함께 기록한다.

## 자동 비교와 출시 기준

동일 원본 버전·가시성·질문·상한에서 A는 기존 관련도 검색, B는 정규화·텍스트 검색, C는 B와 같은 후보에 연결 근거를 추가한 검색이다. 미사용 판정표로 사후 재조정하면 그 자료는 다음 실험의 개발군이다. 첫 비교 결과를 보존한다.

* 적합 장표가 있는 판독 완료 과제에서 상위 1·3개 적중과 후보 포함을 계산한다. 부재는 별도 분모로 잘못 추천한 근거를 검토한다. 질문별 순위·누락·하락을 보존한다.
* 오너 기준은 B−A, C−B 각각 **상위 3개 적중률 +20%p 이상**이다. p95는 각각 A의 120% 이하여야 한다. C가 추가 개선폭에 미달하면 기본 그래프 적용을 보류한다.
* 엔진은 같은 장비·가시성에서 질의별 준비 1회 후 최소 20회 측정하고 실행 순서를 순환한다. p50·nearest-rank p95와 오류·시간 초과를 과제별 기록한다. 첫 화면 완료 시간, 첫 조회와 반복 조회도 분리한다. 기존 5만 문서 운영 부하 판정은 별도다.

## 2차 인계 · 오너의 실제 작성자 시험

화면에서 각 방식을 실행할 수 있고 후보와 미리보기가 준비되면 진행한다. 첫 인계에서는 원본 판정만 수행한다. 동일인이 원본 판정과 사용자 시험을 수행하므로 회상 효과가 남는다. 가능하면 날짜를 달리하고 판정표와 정답을 가린다.

* [trials.tsv](trials.tsv)에 입력 직전부터 적합한 장표 선택 또는 과제 포기까지 시간, 클릭·재검색·추가 입력 횟수, 실제 선택 원본·페이지를 기록한다. 최초 질문은 추가 입력에서 제외한다. 실패·포기는 별도로 표시하고 성공한 사례만 골라 비교하지 않는다.
* 유형 내 비슷한 난이도의 서로 다른 과제를 교차 배정한다. 예시 순서는 T01/A→T02/B→T03/C, T04/B→T05/C→T06/A, T07/C→T08/A→T09/B다. 세부 목적 3개는 판정된 부재·동명 조건을 별도 보고한다. 독립 판정에서 유형 간 난이도나 부재 분포가 맞지 않으면 검색 결과를 보기 전에 배정표를 확정하고 변경 이유를 남긴다.
* 선택 성공률·선택 소요 시간·클릭·재검색·추가 입력 횟수를 방식별, 과제별로 제출한다. 오너 기준은 A 대비 실제 선택 시간 및 조작 횟수 악화 없음이다. 표본 수와 과제 차이가 커 판정이 어려우면 오너에게 판정을 요청한다. 실제 시험 예상 시간은 약 25~45분이다.
