# 제한 평가(2파일 67장) · 독립 봇 판정

새 질문 12개에서 A·B·C 모두 장표를 한 건도 반환하지 않았다. 적합 장표가 있는 과제는 **3개뿐**이었고 세 방식의 상위 3개 적중은 모두 0/3이다. 상위 3개 적중 개선폭은 B−A와 C−B 모두 0%p로 오너 기준 +20%p를 충족하지 못했다. B 출시와 그래프 기본 적용 보류를 유지한다.

| 지표 | A 일반 검색 | B 제품 장표 검색 모드 | C 같은 B 후보 + 연결선 |
|---|---:|---:|---:|
| 장표를 반환한 질문 | 0/12 | 0/12 | 0/12 |
| 적합 과제에서 상위 1개 / 상위 3개 적중 | 0/3 · 0/3 | 0/3 · 0/3 | 0/3 · 0/3 |
| 부재 과제에서 후보를 반환한 횟수 | 0/9 | 0/9 | 0/9 |
| 해당 파일에 적합 장표가 없는 과제·파일 행에서 그 파일을 반환한 횟수 | 0/20 | 0/20 | 0/20 |
| 엔진 p50 / p95 (ms) | 6.00 / 7.6340 | 5.55 / 7.6376 | 5.50 / 7.4432 |
| p95의 A 대비 비율 | 100% | 100.05% | 97.50% |

원본 두 개를 격리된 보관함에 변환·색인했다. 장표 색인의 페이지 행 67개를 확인했다. 제품 버전은 PR #19 병합본이다. B의 자연어 장표 요청 조건에 맞은 질문은 Q01·04·06·08·11 다섯 개였다. 적합 과제 Q01은 전용 경로에서 누락됐고 Q03·09는 기존 관련도 경로에서 누락됐다. 양끝 라벨이 있는 연결선은 8장에 37개였다. B 후보가 없어 C의 승격은 0건이었다. 이번 시험에서는 연결선이 순위를 바꾸는 경우의 효과나 지연을 측정할 수 없었다.

각 질문·방식당 준비 1회 후 20회씩 실행 순서를 교대했다. 전체 p95는 방식별 240회 기준 nearest-rank다. A 대비 120% 허용치는 9.16ms이며 B와 C 모두 이내였다. 오류·순위 변동은 없었다. C의 시간은 제품 B 조회와 메모리 내 그래프 재정렬을 합산했고 그래프 선적재 251.51ms와 프로세스 간 통신을 제외했다. 부재 오탐 0건 및 지연 수치는 전 방식이 빈 결과를 반환한 조건의 측정값이다. 사람이 ‘맞다/아니다’를 표시할 상위 후보 행도 0개였다.

* 독립 봇이 검색 결과 없이 67장 전체의 PPTX 구조와 PowerPoint 내보내기 그림을 확인하고 핵심 9장을 고해상도로 재확인했다. 판독 실패 장은 없다. 일부 작은 화면 안의 세부 글자는 해상도 한계가 있었다. 사람 정답으로 일반화하지 않는다.
* 새 질문의 작성 현실성은 11/12가 적합했고 Q11은 제외 조건이 어색해 불명확했다. 원래의 12개를 모두 채점했다. 24개 과제·파일 행 중 4개 행에 적합 장표가 있었고, 5개 과제·장표 조합이 Q01·03·09에 집중됐다. Q09의 화면 표준 예시 1개는 약한 적합이었다. Q05의 확대 대상과 Q06의 기한 근거가 다른 장은 오답으로 유지했다.
* 후보 경로와 질의 해석 개선 여부는 다음 범위 결정 사항이다. 제한 평가 결과를 보존한 상태에서 이 질문으로 조정한 뒤 같은 묶음을 새 독립 성적으로 재사용할 수 없다.
